# 💊 تذكير الدواء — منظم أدويتك الذكي

تطبيق عربي مجاني لإدارة الأدوية وتذكير الجرعات، يعمل على الهاتف والكمبيوتر، **بدون إنترنت وبدون خوادم**. بيانات المستخدم تبقى على جهازه فقط (خصوصية كاملة).

## 🚀 التشغيل

### الطريقة 1 — مباشرة (الأسهل)
افتح الملف `index.html` في أي متصفح حديث (Chrome / Edge / Firefox / Safari).

### الطريقة 2 — خادم محلي (موصى به للتثبيت والإشعارات)
```bash
# من داخل مجلد المشروع
npx serve .
# أو
python -m http.server 8080
```
ثم افتح `http://localhost:8080`

## 📱 التثبيت على الهاتف (PWA)

### أندرويد (Chrome)
1. افتح التطبيق في Chrome
2. اضغط قائمة ⋮ → **"إضافة إلى الشاشة الرئيسية"**
3. سيظهر أيقونة التطبيق على شاشتك — يعمل كتطبيق كامل

### آيفون (Safari)
1. افتح التطبيق في Safari
2. اضغط زر المشاركة ⬆️ → **"إضافة إلى الشاشة الرئيسية"**
3. افتحه من الشاشة الرئيسية — يعمل بملء الشاشة

## 🌐 النشر على الإنترنت (مجاناً)

### الخيار 1 — GitHub Pages (مجاني للأبد)
```bash
git init
git add .
git commit -m "تذكير الدواء v1.0"
# أنشئ مستودعاً على GitHub ثم:
git remote add origin https://github.com/اسمك/med-reminder.git
git push -u origin main
# Settings → Pages → اختر main branch → نشر
# سيصبح التطبيق متاحاً على: https://اسمك.github.io/med-reminder/
```

### الخيار 2 — Netlify Drop (بدون أوامر)
1. ادخل على [netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد المشروع وأفلته
3. تحصل على رابط فوري مثل `https://med-reminder.netlify.app`

### الخيار 3 — Vercel
```bash
npx vercel
```
